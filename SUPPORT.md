# Support

## How to file issues and get help

This project uses [GitHub Issues](../../issues) to track bugs and feature requests.
Please search the existing issues before filing new issues to avoid duplicates. For
new issues, file your bug or feature request as a new issue.

When reporting a bug, please include:

- The utility/notebook/script involved (e.g., `fabric-warehouse-lakehouse-metrics.ipynb`)
- Your Fabric capacity type and runtime version
- Steps to reproduce
- The full error message or stack trace
- What you expected to happen

For help and questions about using this project, please open a
[GitHub Discussion](../../discussions) or a GitHub Issue with the `question` label.

## Microsoft Support Policy

Support for this project is limited to the resources listed above. This is a
community-driven, open-source project provided **as-is**. It is **not** covered by
any Microsoft support agreement, SLA, or Microsoft Premier/Unified Support. It is
not an official Microsoft product.
